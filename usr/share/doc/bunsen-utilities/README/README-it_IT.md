bunsen-utilities  
================  

Una raccolta di piccoli script che offrono diverse funzionalità  
utili agli utenti di BunsenLinux e agli amministratori di sistema.  

beepmein:               Script per la sveglia basato su "at".  

bl-imgbb-upload:        Acquisisce schermate e le carica su Imgbb.  
bl-imgur-upload:        Acquisisce schermate e le carica su Imgur.  
bl-image-upload:        Utilità generica di BunsenLabs per il caricamento delle immagini.  

bl-conkyedit:           Cerca e modifica i file di configurazione di Conky.  
bl-conky-manager:       Gestore di Conky basato su Yad.  
bl-conkymove:           Aiuta a spostare le finestre di Conky.  
bl-conky-session:       Gestisce più sessioni di Conky.  

bl-kb:                  Legge le scorciatoie da tastiera di Openbox e le salva in un file di testo.  
bl-xbk:                 Analizza le configurazioni di xbindkeys e salva le scorciatoie nello stesso file di testo utilizzato da bl-kb.  
bl-lock:                Blocca lo schermo (richiede bunsen-exit).  
bl-setlocale:           Script basato su Yad che consente di scegliere le impostazioni locali.  

bl-pkg-versions:        Mostra le versioni dei pacchetti BunsenLabs nel repository APT e su GitHub.  
bl-notify-broadcast:    Invia notifiche popup agli utenti da processi eseguiti come root.  
bl-urxlx:               Converte i colori Xresources in RGB per la configurazione di lxterminal.  
bl-xinerama-prop:       Recupera le proprietà di Xinerama tramite uno script shell.  
bl-reload-gtk23:        Notifica alle applicazioni GTK2/3 le modifiche alla configurazione, ad esempio quelle dei temi.  

xml2xconf:              Converte le voci dei file XML di configurazione di xfce4 (xfconf) in comandi xfconf-query.  

NOTA: tint2 non fa più parte del desktop predefinito di BunsenLabs,  
ma queste utilità continuano a essere distribuite con questo pacchetto:  

bl-tint2edit:           Cerca e modifica i file di configurazione di tint2.  
bl-tint2-manager:       Gestore di tint2 basato su Yad.  
bl-tint2-restart:       Riavvia tutti i processi tint2 in esecuzione.  
bl-tint2-session:       Gestisce più sessioni di tint2.
