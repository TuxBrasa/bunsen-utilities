bunsen-utilities  
================  

Набор небольших скриптов, предоставляющих различные функции,  
полезные пользователям BunsenLinux и системным администраторам.  

beepmein:               Скрипт будильника на основе команды "at".  

bl-imgbb-upload:        Делает снимки экрана и загружает их на Imgbb.  
bl-imgur-upload:        Делает снимки экрана и загружает их на Imgur.  
bl-image-upload:        Универсальная утилита BunsenLabs для загрузки изображений.  

bl-conkyedit:           Находит и редактирует файлы конфигурации Conky.  
bl-conky-manager:       Менеджер Conky на основе Yad.  
bl-conkymove:           Помогает перемещать окна Conky.  
bl-conky-session:       Управляет несколькими сеансами Conky.  

bl-kb:                  Читает сочетания клавиш Openbox и записывает их в текстовый файл.  
bl-xbk:                 Анализирует конфигурации xbindkeys и записывает сочетания клавиш в тот же файл, что и bl-kb.  
bl-lock:                Блокирует экран (требуется bunsen-exit).  
bl-setlocale:           Скрипт на основе Yad для выбора региональных настроек.  

bl-pkg-versions:        Отображает версии пакетов BunsenLabs в репозитории APT и на GitHub.  
bl-notify-broadcast:    Отправляет пользователям всплывающие уведомления из процессов, запущенных от имени root.  
bl-urxlx:               Преобразует цвета Xresources в RGB для настройки lxterminal.  
bl-xinerama-prop:       Получает свойства Xinerama с помощью shell-скрипта.  
bl-reload-gtk23:        Уведомляет приложения GTK2/3 об изменениях конфигурации, например темы оформления.  

xml2xconf:              Преобразует записи XML-файлов конфигурации xfce4 (xfconf) в команды xfconf-query.  

ПРИМЕЧАНИЕ: tint2 больше не входит в стандартное окружение рабочего стола BunsenLabs,  
однако следующие утилиты по-прежнему поставляются в составе этого пакета:  

bl-tint2edit:           Находит и редактирует файлы конфигурации tint2.  
bl-tint2-manager:       Менеджер tint2 на основе Yad.  
bl-tint2-restart:       Перезапускает все работающие процессы tint2.  
bl-tint2-session:       Управляет несколькими сеансами tint2.
