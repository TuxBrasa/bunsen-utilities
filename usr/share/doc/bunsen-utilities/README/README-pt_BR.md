bunsen-utilities  
================  

Uma coleção de pequenos scripts que oferecem diversas funcionalidades  
úteis para usuários do BunsenLinux e administradores de sistemas.  

beepmein:               Script de despertador baseado no comando "at".  

bl-imgbb-upload:        Captura telas e envia as imagens para o Imgbb.  
bl-imgur-upload:        Captura telas e envia as imagens para o Imgur.  
bl-image-upload:        Utilitário genérico do BunsenLabs para envio de imagens.  

bl-conkyedit:           Localiza e edita arquivos de configuração do Conky.  
bl-conky-manager:       Gerenciador do Conky baseado no Yad.  
bl-conkymove:           Auxilia no reposicionamento das janelas do Conky.  
bl-conky-session:       Gerencia múltiplas sessões do Conky.  

bl-kb:                  Lê os atalhos de teclado do Openbox e os grava em um arquivo de texto.  
bl-xbk:                 Analisa configurações do xbindkeys e grava os atalhos no mesmo arquivo de texto usado pelo bl-kb.  
bl-lock:                Bloqueia a tela (requer o bunsen-exit).  
bl-setlocale:           Script baseado no Yad que permite aos usuários escolher sua localidade (locale).  

bl-pkg-versions:        Exibe as versões dos pacotes do BunsenLabs disponíveis no repositório APT e no GitHub.  
bl-notify-broadcast:    Envia notificações pop-up aos usuários a partir de processos executados como root.  
bl-urxlx:               Converte as cores do Xresources para RGB para uso na configuração do lxterminal.  
bl-xinerama-prop:       Obtém as propriedades do Xinerama em um script de shell.  
bl-reload-gtk23:        Notifica os aplicativos GTK2/3 sobre alterações na configuração, como mudanças de tema.  

xml2xconf:              Converte entradas de arquivos XML de configuração do xfce4 (xfconf) em comandos xfconf-query.  

OBSERVAÇÃO: O tint2 não faz mais parte do ambiente de desktop padrão do BunsenLabs,  
mas estes utilitários continuam sendo distribuídos neste pacote:  

bl-tint2edit:           Localiza e edita arquivos de configuração do tint2.  
bl-tint2-manager:       Gerenciador do tint2 baseado no Yad.  
bl-tint2-restart:       Reinicia todos os processos do tint2 em execução.  
bl-tint2-session:       Gerencia múltiplas sessões do tint2.
