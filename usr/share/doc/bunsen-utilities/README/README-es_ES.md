bunsen-utilities  
================  

Una colección de pequeños scripts que proporcionan diversas funciones  
útiles para los usuarios de BunsenLinux y los administradores de sistemas.  

beepmein:               Script de alarma basado en "at".  

bl-imgbb-upload:        Captura pantallas y sube las imágenes a Imgbb.  
bl-imgur-upload:        Captura pantallas y sube las imágenes a Imgur.  
bl-image-upload:        Utilidad genérica de BunsenLabs para subir imágenes.  

bl-conkyedit:           Busca y edita archivos de configuración de Conky.  
bl-conky-manager:       Administrador de Conky basado en Yad.  
bl-conkymove:           Ayuda a mover las ventanas de Conky.  
bl-conky-session:       Gestiona múltiples sesiones de Conky.  

bl-kb:                  Lee los atajos de teclado de Openbox y los guarda en un archivo de texto.  
bl-xbk:                 Analiza las configuraciones de xbindkeys y guarda los atajos en el mismo archivo de texto que bl-kb.  
bl-lock:                Bloquea la pantalla (requiere bunsen-exit).  
bl-setlocale:           Script basado en Yad que permite elegir la configuración regional.  

bl-pkg-versions:        Muestra las versiones de los paquetes de BunsenLabs en el repositorio APT y en GitHub.  
bl-notify-broadcast:    Envía notificaciones emergentes a los usuarios desde procesos ejecutados como root.  
bl-urxlx:               Convierte los colores de Xresources a RGB para la configuración de lxterminal.  
bl-xinerama-prop:       Obtiene las propiedades de Xinerama mediante un script de shell.  
bl-reload-gtk23:        Notifica a las aplicaciones GTK2/3 sobre cambios de configuración, como los temas.  

xml2xconf:              Convierte entradas de archivos XML de configuración de xfce4 (xfconf) en comandos xfconf-query.  

NOTA: tint2 ya no forma parte del escritorio predeterminado de BunsenLabs,  
pero estas utilidades siguen distribuyéndose con este paquete:  

bl-tint2edit:           Busca y edita archivos de configuración de tint2.  
bl-tint2-manager:       Administrador de tint2 basado en Yad.  
bl-tint2-restart:       Reinicia todos los procesos de tint2 en ejecución.  
bl-tint2-session:       Gestiona múltiples sesiones de tint2.
