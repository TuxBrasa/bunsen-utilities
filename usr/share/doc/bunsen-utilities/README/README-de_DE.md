bunsen-utilities
================

Eine Sammlung kleiner Skripte mit verschiedenen Funktionen,
die für BunsenLinux-Benutzer und Systemadministratoren nützlich sein können.

beepmein:               Wecker-Skript auf Basis von "at".

bl-imgbb-upload:        Erstellt Screenshots und lädt sie zu Imgbb hoch.
bl-imgur-upload:        Erstellt Screenshots und lädt sie zu Imgur hoch.
bl-image-upload:        Allgemeines BunsenLabs-Dienstprogramm zum Hochladen von Bildern.

bl-conkyedit:           Findet und bearbeitet Conky-Konfigurationsdateien.
bl-conky-manager:       Yad-basierter Conky-Manager.
bl-conkymove:           Unterstützt das Verschieben von Conky-Fenstern.
bl-conky-session:       Verwaltet mehrere Conky-Sitzungen.

bl-kb:                  Liest Openbox-Tastenkombinationen aus und schreibt sie in eine Textdatei.
bl-xbk:                 Analysiert xbindkeys-Konfigurationen und schreibt die Tastenkombinationen in dieselbe Textdatei wie bl-kb.
bl-lock:                Sperrt den Bildschirm (erfordert bunsen-exit).
bl-setlocale:           Yad-basiertes Skript zur Auswahl der Spracheinstellungen.

bl-pkg-versions:        Zeigt die Versionen der BunsenLabs-Pakete im APT-Repository und auf GitHub an.
bl-notify-broadcast:    Sendet Benutzerbenachrichtigungen aus Root-Prozessen.
bl-urxlx:               Konvertiert Xresources-Farben für die lxterminal-Konfiguration in RGB.
bl-xinerama-prop:       Liest Xinerama-Eigenschaften in einem Shell-Skript aus.
bl-reload-gtk23:        Benachrichtigt GTK2/3-Anwendungen über Änderungen an der Konfiguration, z. B. am Design.

xml2xconf:              Konvertiert Einträge aus xfce4-xfconf-XML-Dateien in xfconf-query-Befehle.

HINWEIS: tint2 gehört nicht mehr zum standardmäßigen BunsenLabs-Desktop,
diese Dienstprogramme werden jedoch weiterhin mit diesem Paket ausgeliefert:

bl-tint2edit:           Findet und bearbeitet tint2-Konfigurationsdateien.
bl-tint2-manager:       Yad-basierter tint2-Manager.
bl-tint2-restart:       Startet alle laufenden tint2-Prozesse neu.
bl-tint2-session:       Verwaltet mehrere tint2-Sitzungen.
