bunsen-utilities
================

Uma coleção de pequenos scripts que disponibilizam várias funcionalidades
úteis para os utilizadores do BunsenLinux e os administradores de sistemas.

beepmein:               Script de despertador baseado no comando "at".

bl-imgbb-upload:        Captura ecrãs e envia as imagens para o Imgbb.
bl-imgur-upload:        Captura ecrãs e envia as imagens para o Imgur.
bl-image-upload:        Utilitário genérico do BunsenLabs para o envio de imagens.

bl-conkyedit:           Localiza e edita ficheiros de configuração do Conky.
bl-conky-manager:       Gestor do Conky baseado no Yad.
bl-conkymove:           Ajuda a mover as janelas do Conky.
bl-conky-session:       Gere várias sessões do Conky.

bl-kb:                  Lê os atalhos de teclado do Openbox e guarda-os num ficheiro de texto.
bl-xbk:                 Analisa as configurações do xbindkeys e guarda os atalhos no mesmo ficheiro de texto utilizado pelo bl-kb.
bl-lock:                Bloqueia o ecrã (requer o bunsen-exit).
bl-setlocale:           Script baseado no Yad que permite escolher as definições regionais.

bl-pkg-versions:        Apresenta as versões dos pacotes do BunsenLabs no repositório APT e no GitHub.
bl-notify-broadcast:    Envia notificações pop-up aos utilizadores a partir de processos executados como root.
bl-urxlx:               Converte as cores do Xresources para RGB para a configuração do lxterminal.
bl-xinerama-prop:       Obtém as propriedades do Xinerama através de um script de shell.
bl-reload-gtk23:        Notifica as aplicações GTK2/3 sobre alterações de configuração, como os temas.

xml2xconf:              Converte entradas de ficheiros XML de configuração do xfce4 (xfconf) em comandos xfconf-query.

NOTA: o tint2 já não faz parte do ambiente de trabalho predefinido do BunsenLabs,
mas estes utilitários continuam a ser distribuídos com este pacote:

bl-tint2edit:           Localiza e edita ficheiros de configuração do tint2.
bl-tint2-manager:       Gestor do tint2 baseado no Yad.
bl-tint2-restart:       Reinicia todos os processos tint2 em execução.
bl-tint2-session:       Gere várias sessões do tint2.
